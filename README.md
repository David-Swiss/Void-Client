# VOID Client

A lightweight, client-side Fabric utility HUD for Minecraft 26.2.

## Features
- Minimal black and purple VOID HUD
- FPS counter (F6)
- Coordinates display (F7)
- HUD overlay toggle (F8)
- Menu/status panel (Right Shift)
- All key bindings can be changed in Minecraft Options > Controls

## Build
Requires Java 25. Run:

```bash
gradle build
```

The mod JAR is created in `build/libs/`.

## Install
Install Fabric Loader for Minecraft 26.2 and Fabric API, then place the VOID JAR in the `mods` folder.

This project is a simple client-side HUD utility. It does not include anti-cheat bypasses or stealth features.
